# WEB-020：素材来源、使用范围与体积预算

基线 `c1e208a`，2026-10-22工作树只读盘点。范围是本项目网页的小范围自娱试玩；用户已确认现有素材可用，并在本轮明确无需额外追索授权材料。本文记录实际来源路径、候选范围、缺失边界和迁移预算，不执行021以后的布局、转换、资源接入或音频开发。

仓库项目级 [LICENSE](../LICENSE) 标示MIT与项目作者；素材外部原始出处/作者资料未找到，文件名和曲名不作为出处证明。使用范围按上述用户确认记录，不据项目LICENSE另写素材独立授权结论。018的[日文目录](web-japanese-display-catalog.md)仍负责文字证据，A06仍未通过。

## 4. Web体积预算与加载边界

以下是020确定的**工程目标上限**，供022/026/042核算与调整，不是已经测得或已经实现的结果，也不涉及购买带宽/存储。全量静态选集预算只计浏览器文件，排除后端JAR、源WAV、存档及构建依赖。

| 项目 | 目标上限 | 口径与落实任务 |
|---|---:|---|
| HTML+JS+CSS（含019台词） | 1MiB原始；512KiB压缩传输 | 全部代码块合计，不靠拆chunk漏计；042含台词回归与体积对比 |
| 全部选用图片 | 32MiB；单图512KiB | 022根据021舞台尺寸转码，保留透明度/必要细节，实测效果后定格式；未达标先报告原因，不擅删角色/场景 |
| 全部BGM | 64MiB；单首5MiB | 026选浏览器格式并听审；128kbit/s×3482.292秒约53.14MiB（不含封装/备用格式），只作可行性估算，非编码承诺 |
| 全部音效 | 1MiB | 9项按需/必要小集合加载，026/028验证音质与时机 |
| 帮助/BGM说明/图片与音频清单等 | 1MiB | JSON/文本原始体积；台词已计JS，不再计一次；022/026/029 |
| 预留 | 1MiB | 超支必须列明原因与受影响组，先在相应任务调整预算，不能悄悄扩大 |
| **全部静态文件合计** | **100MiB** | 以上各组相加；如发布兼容备用编码，全部格式都占整包预算，不能只计选中格式 |

加载目标：冷缓存首页（HTML/JS/CSS+当页图片）≤**1.5MiB实际压缩传输**；开村后首次舞台所需新增图片/数据≤**3MiB**。音频由手势解锁后按需取当前曲目，单首上限如上，不计入“无需音频即可读完事件”的页面必要传输，也不能用此口径掩盖整包100MiB上限。首曲若在首页下载，必须计入首页1.5MiB。未出现的角色表情、后续场景和其他BGM不在启动时全量预拉。

缓存/哈希由022/026/042建立；浏览器资源缓存不冒充Replay或战绩存储。流量100人估算应按**实际下载量×访客数×缓存命中情况**计算：最坏100次全包冷下载约9.77GiB，首页1.5MiB×100约150MiB；它们不是100并发承诺或服务器容量验证，047另行测量。解码内存、音频释放及画质验收也不以压缩文件大小代替。
