# WEB-050-B1 对话窗口与统一阅读

本批恢复核心对话窗口及阅读节奏，尚非050整体完成。用户已查看真实桌面参考，确认方向并要求对话框下移；投票窗口为B2、完整结算为C，字体分发、其余布局与日文化继续按050计划处理。实现位于独立本地分支，不混入WF-008的PR #12。

## 窗口与交互

- 1280×720舞台，沿用原版`messageframe.png`；框left260/top490/width760/height230。相对桌面top450下移40为用户批准差异，底边贴720并遮住人物底部690截断处。
- 正文与日数共用50ms逐字引擎，按Unicode码点显示。首次点击文字或继续仅补全；完整阅读后再次继续才确认当前事件。消息框重建、处刑二段和日数继续后保留原继续按钮焦点；若用户转向菜单/弹窗则不抢回。文字选择、滚动不触发确认，长文保留原生滚动、独立继续按钮和键盘路径。
- 夜死图片仍按1000ms展示第二帧，画面就绪后2000ms开始台词；处刑先显示主台词，显式本地继续后切结果图和音效，隐藏消息框2000ms，再逐字显示结果；结果读完才能确认。减少动态效果跳过逐字与结果等待，仍需显式本地继续。
- busy/不确定时暂停阅读并禁确认；事件切换、卸载、刷新取消旧计时器。图片失败/挂起给出本地诊断与有限等待，也可显式选择无图阅读，不能因图片永久阻塞业务。
- EVENT编号、素材说明、公开相关人物等移到窗口外折叠说明；不新增隐藏身份或私有调试数据。全句辅助阅读文本不随每字反复播报。

只改前端本地展示；不改规则、生产Java、API、身份公开门槛、会话/Replay/战绩格式。确认仍通过既有`nextEvent`增加并保存本地游标，不伪造服务器写请求。

## 字体与预算边界

游戏区使用现有系统字体回退，去除Inter优先；本机未安装Takao Mincho，不能声称跨设备字体已经与桌面一致。本批不安装/分发字体、不加依赖，最终字体仍须来源/许可/样张/加载与预算前置门。

新增当前消息框的实际图片请求仍计入大厅1.5MiB、首局新增3MiB、全站100MiB原预算。未给字体或消息框额外预算，未调整阈值。

## 测试前提与断言变化

- 专项`desktop-dialogue.spec.js`与`night-day.spec.js`使用基础fixture，严格检查真实生产时序、本地补全零写入和游标最后仅增一次。
- 旧业务旅程显式完成本地阅读后再继续或采集文本；夹具不点击最终`next-event`，不代投票、不改权威状态。原先在新台词为空时取样再与刷新后全句比较不再成立；改为补完当前台词再取样，原文本相等/游标/存储/权威断言保留。七配役姓名断言随标题栏迁移改为精确核对`.message-speaker`，不再从已移除的正文辅助元信息查找姓名。
- 处刑原“自动换图/提前确认跳过结果”的前提由本批批准交互取代；仍断言实际第二帧才有处刑音、只播一次、刷新取消旧场景、减少动态效果也不能自动越过确认。
- 图片白名单只增加实际当前使用的`messageframe.png`，不放行未来资源；全部原预算保留。
- `drainEvents`增加本地reading状态；120上限仍计真实事件确认数，不把补全/转场当一次确认，也不把暂时缺少next当已收敛。
