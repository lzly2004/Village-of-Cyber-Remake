## 桌面锚点与信息边界

结算按EndAnimeHandler、GameStrings逐项映射：公称職業/真の職業，精确的死亡日与狼噛/処刑/呪殺/後追/猫呪；白天/夜晚后追和猫呪都保留服务端死亡日期。村胜的存活者是最終存活；狼胜的人狼/狂人/狂信者、狐胜的妖狐/背徳者是最終胜利，其余仍alive者显示桌面的最終死亡，绝不由此生成死亡日期。保留桌面原有“存活/胜利”字形，最终语言统一仍属050。

组件只在phase FINISHED且currentEvent为空时挂载；settlementDetails(false,...)不读取参数字段，revealedRoles仍经既有严格完整校验。未知/提前脱敏死因NIGHT_DEATH、非法日数和角色保持明确诊断，不猜测、不用actualRole直接读取VisiblePlayer。

结算胜利标题与人物占完整场景，取消旧绿色结论框。人物按桌面前半第一行/后半第二行，以104px间隔浏览，每卡有头像及公称/真职业/结局；大名单横向浏览。窄窗口以页面纵向滚动容纳完整结算，不再在短框内裁掉第二行。

投票布局按GameSceneVoteHandler/PlayerStatusRenderer/VoteInfoRenderer/VoteButtonPanel：顶部两排公开头像、右上日数/人数/吊绳、左下公开信息及指示、右侧原版菜单/回避/指示/记录/投票按钮图。GameOrders仅迁移现有模板与回调，选择和命令仍由useGuestGame唯一持有；读台词期间仍显示原来禁用的CO/技能控件，没有因迁移而消失或开放操作。不自动代投、不变更合法候选、冲突和不确定锁。
