## 桌面来源与两条路径

先核对局内`VoteInfoRenderer`与`UIHelpers.appendSkillResultLog`，再对照`ReplayTextFormatter`、`ReplayPlayerHandler`、`ReplaySave.getVisibleSkillTarget`、`DaySnapshot.isAlive`、`ImageNames.skillResultIcon`及[030契约](web-replay-exchange.md)。不复制局内投影的公开限制来删除终局录像已有私有资料，也不把Replay信息接入活局。

- 信息栏：人物分类先取显示日+1的快照，缺失再取显示日；占卜/灵能均从技能日1、护卫从2，到显示日之前。不同于局内灵能从2，这是既有Replay兼容行为。技能日+1快照负责死亡日截断/目标外观映射，`getVisibleSkillTarget`则按playerIndex搜索不晚于显示日+1的最新完整history；显式0即0，无history才读**精确**技能日+1的旧st，不使用位置回退补造st。
- `nonHumanMarked`读技能当日，最后再检查显示当日；不提前读下一日标记。末日信息栏按职业ordinal 1—11分组，名单顺序保留快照数组顺序；末日优先职业表，不能借“投票”覆盖末日板。原始formatter的`破绽`在网页显示为日文`破綻`，正常职业标签沿用023日文映射，不改数据。
- 处刑/死体按完成日1..显示日-1，读其下一日快照：猫又处刑项跳过，由猫咒受害者的猫又前缀显示；狐处刑仅背德先死才列名，后追带狐前缀；夜死4—7只作死体名单，没人则平和；不猜不存在的职业或死亡原因。保留桌面原拼接（同日多个项并非自动补分隔符）。
- 结果图是**另一条路径**：累计快照日2..显示日的st；claimedRole>0时取claimedRole，否则actualRole，限占卜/灵能；`isAlive(d)`为deathDay==0或>d，死亡当日不发图；顺位<=0按1。没有完整history覆盖这一条的st。角色1图支持顺位1—5、角色2图1—4；越界保留实际文字与SKILL_ICON_UNAVAILABLE，不伪造图或请求未知路径。所有可用图命中022清单，无素材重建。
- 快照查找沿用033的精确dayNumber→旧day-1位置回退，任何代用明确代码/请求日/真实来源日；缺日SKILL_RECORD_MISSING/SNAPSHOT_MISSING等诊断不禁用日期/关闭。不把缺历史视为已知技能结果。Java的旧位置索引用于文本的数组位置映射，与技能history搜索playerIndex保持独立，外观编号不替代玩家索引。

## 网页交互与差异

信息、票型与技能结果图均只读同一份内存录像，无fetch/API/存储写入；纯文本插值，没有v-html。未CO真实结果仅在标明历史/真实职业的录像dialog内展示；不改进行中对局的公开投影、事件确认/恢复、预约、BGM生命周期或揭晓门槛。关闭返回列表，刷新仍关闭播放并恢复活局；浏览不恢复录像为对局，不累计战绩。

票型取显示日快照，三种方式与两类候补索引保持：灰名单按玩家数组位置取外观，指定名单直接是characterNumber。按快照原轮次顺序浏览，边界夹取；得票从正目标累加，0和缺投票按桌面显示棄権，死亡日当日玩家仍列出，早于该日死者不列；不推断“本应投票”、不增加平票/处刑结论。-1明确“方式未记录”，不冒充自由投票。桌面的前10行/剩余行左右分栏改成连续可访问table，仍按原数组顺序完整列人，44行不截断。

与桌面相同，非首轮投票暂不能切日期；先回首轮或信息栏。网页返回信息栏即重置轮次，避免桌面隐藏轮次仍挡住日期的交互死角。缺本日票型时明确无记录、投票入口禁用，日期仍可用。日期/轮次、折叠仅存在内存，不增存储。

技能图不按桌面绝对坐标叠在头像上，改为单独可展开列表，逐条标日期/来源日、角色/顺位、目标和黑白结果，防止遮挡033已修的两行人物；折叠时不请求结果图，打开后走既有AssetImage/共享manifest与可视加载。图区和文本历史分别说明记录时点差异，不声称两条路径总一致。损图仍有文字、既有可访问诊断和导航。角色卡/信息/票表不新设内部纵向高度裁切，长内容使用外层原生dialog滚动；这不代表所有日期/人物/表格同时全屏，正式DPI/辅助技术仍归046。

采纳033 N-4：弹窗补“关闭后恢复当前场景默认曲，手选曲请重选”提示，仅文案，原计数/音频选择不变。N-2/N-3窄屏/缩放/多屏横向观感登记046，本轮不重排任务或宣称正式验收。
