# WEB-037 浏览器战绩统计页面

基线main 5d30cd9。从侧栏“戦績を見る”打开原生模态窗口，支持総合及原peiyi顺序七配役。仅使用036的createRecordStore().read()一致只读事务，未修改账本/IndexedDB版本、入账时机、规则、Java、协议、Replay或依赖；不读取活局/Replay/真实身份来推导统计。不接入新图片或音频，不切换BGM场景、不解锁音频。

## 展示契约

对应RecordSceneHandler：総合显示总局数、村胜率、最大连胜及村/狼/狐胜场；各配役另显示当前连胜。総合没有虚构“跨配役当前连胜”，最大值取各配役最大。当前连胜只被本配役非村胜打断，别的村不打断。五位HALF_UP由036账本聚合计算；页面仅toFixed(5)保留尾零，不重新统计/解释wincnt。空库/无该配役显示0回、0.00000%及明确空态，不能把读取失败当空库。

每次打开/显式“戦績を再読み込み”读取一次提交完成的快照；切换配役只选择内存快照，不写回、不自动轮询/监听其他标签。跨标签新结果在手动刷新后显示，页面有时点说明。刷新先撤下旧数值，失败显示白名单诊断（INVALID_HISTORY/STORAGE_UNAVAILABLE/STORAGE_BLOCKED/STORAGE_TIMEOUT），不会保留旧数值冒充刷新成功；可重试、可关闭。在途读取完成受版本控制，卸载后不发布旧结果，不自动重新打开窗口。

模态窗口保留对局组件、游标、会话；显式关闭/Escape返回入口焦点，Tab/Shift+Tab保持模态内。按内容自然高度，只在整个窗口超出视口时原生纵向滚动；无局部卡片高度上限，没有“同屏展示全部”的承诺。统计按钮瞬时切换背景，不继承全局背景动画造成短暂低对比。范围说明、读取状态/诊断、配役按钮aria-pressed、原生dl字段及焦点轮廓可被辅助技术读取；正式辅助技术/DPI验收仍属046。

浏览器共用、同origin、跨设备不自动同步、清站点数据会丢失均显式说明；修正大厅“战绩仅随服务结束的一次性记录”旧文案为浏览器保存。读取可创建空036数据库，但页面不调用record()、add/put/delete/clear，不从未知来源补记。既有036终局入账流程可独立完成，页面不阻断它。
