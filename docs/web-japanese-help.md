## 交互边界

菜单在侧栏常驻；帮助按需加载为独立chunk，首次失败/15秒超时显示HELP_LOAD_FAILED并可关闭，业务控件不被禁用。原文与要约均使用插值，禁止v-html。

原生dialog提供模态焦点约束、Esc关闭与焦点返回；对局组件保持挂载，游标、阅读容器滚动、权威更新、预约不因查看帮助而改变。帮助按钮位于main外，不进入既有CLICK捕获，不解锁或切换音乐；原有声音可能继续播放。查看配役不会自动选择或开局。刷新不持久化帮助页；正常会话恢复不变。
