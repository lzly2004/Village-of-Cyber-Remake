## 本局访问能力

继续使用创建返回的随机UUID v4作为本局访问凭据；响应、Location、URL及sessionStorage形状不变，不新增账号/用户标识、cookie、查询列表或持久化服务端会话。持有凭据即可读取/操作该局，包括复制给另一个浏览器；“隔离游客”指独立创建的会话对象、版本、事件与内存战绩隔离，不承诺同一个已泄露凭据仍能区分其持有者。浏览器只在同一标签页sessionStorage保存`{sessionId,eventCursor}`，不把访问凭据另存localStorage、IndexedDB或Replay。累计战绩仍沿用036的局ID摘要去重，非服务端身份。

服务端仅接受规范小写UUID v4。未知、畸形、过期、已释放或服务重启后丢失的凭据均返回相同`404 GAME_NOT_FOUND`有界响应，不回显输入，不区分存在性原因。前端只在该状态+code组合下清本局凭据/游标及展示状态，明确告知可能的空闲/最长时限/释放/重启原因；不清本地录像、战绩或无关存储。其他JSON 404保留凭据；无法解析的HTML/网络失败保留并按不确定恢复。错误分类的全面落实归040。

响应`Cache-Control: no-store`，增加`Referrer-Policy: no-referrer`；HTML入口也使用no-referrer。UUID本身不可当日志中的普通公开标识：路径、Location、正文与异常链的全面日志审计仍归041/044，HTTPS及同源托管归043，不凭本轮宣布公网安全就绪。

## 生命周期与确定边界

| 参数 | 当前生产值与语义 |
|---|---|
| 总会话容量 | 100，包含创建占位、存续会话及尚未结束的退役在途请求；不是100并发SLA |
| 空闲TTL | 30分钟，从创建完成或最近已接受请求完成起计；精确`>=`失效 |
| 最长存续 | 24小时，从创建完成起计，任何访问都不能延期；精确`>=`失效 |
| 定时回收 | 服务成功启动后每60秒扫描；无请求的孤儿局也会回收 |
| 入口补扫 | 创建、会话访问及释放前扫描；过期局不能靠等待下一轮定时器继续访问，容量满时先回收已过期者 |

使用`System.nanoTime()`的经过时间差，时钟回拨/时区不延长TTL，测试注入单调时钟，覆盖计数环绕。策略是代码中的显式默认值，不本轮新增系统属性/环境配置/CLI参数；测试包内构造器可缩短时限并控制时间。047量测后若需调整参数须说明新边界与测试，不自行把100会话上限当性能证明。

任一已接受的GET/写命令会续空闲期（包括后续应用校验失败）；041执行前429不取得借用、不续空闲期；本地逐条确认、阅读、Replay、战绩浏览不请求服务器，因此不续期。不加心跳、不后台推进、不自动重发创建/写入。最长时限避免持有凭据持续访问使会话无限存续。终局与运行中使用同一TTL：未及时保存的终局Replay可能随会话失效而无法再次从服务端取得，本地已保存文件不受影响。24小时是一局上限，不是允许任意长局的承诺。

## 并发与资源释放

注册表锁只保护容量/发布/借用计数，不在其内执行核心命令或关闭对局。创建仍先原子保留容量，在锁外启动规则，再检查关服状态发布；失败或关服不发布并释放候选。容量满时返回确定的`503 SESSION_LIMIT`，不驱逐仍有效的其他游客、不创建新局；前端显示明确拒绝，不自动重试。

每个按ID访问的HTTP路由（含终局Replay提取）都通过`withSession`取得在途借用，`finally`归还。扫描不关闭在途命令；到达最长时限或DELETE退役后拒绝新的借用，已有请求可以完成。最后一个请求退出后摘除、关闭并解除注册表引用；无法借回失效对象。DELETE不撤销已接受命令，不承诺强制中断。若核心请求永久不返回，借用会继续占容量；041应用入口名额/频率限制见[安全与请求限额](web-http-security.md)，047仍需压力/挂起量测，不用不安全线程中断/擅自驱逐解决。

无在途请求时扫描或DELETE直接摘除并在注册表锁外close。服务关闭停止定时器、清注册表并关闭会话；在途创建随后完成也不会重新发布。close幂等。回收失败记录明确诊断，不让定时任务因一次RuntimeException默默永久停机。039当时未修改全局日志配置；041起独立Web进程在start关闭DebugLogger并改用固定事件诊断，当前日志边界见[安全与请求限额](web-http-security.md)。
