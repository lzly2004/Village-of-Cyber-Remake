## 1. 首发定位与明确排除

- 交付正式联网 Web：核心功能与桌面实际行为对等，保留原版主要视觉、日文界面/角色名/台词及音频，而不是仅能投票通关的文本试玩版。
- 必含全部 CO、技能预约、全部投票方式、公开信息/票型浏览、Replay、累计战绩与帮助。浏览器交互可以适配，但不得擅自改变规则、信息公开范围或操作语义。
- 游客游玩，无账号、登录、云端战绩或跨设备自动同步。现有规则 AI 保留；首发任何环节均不接入 LLM。
- 电脑优先，不要求手机访问或可玩；不发行本地 Web 启动包。原 Swing 产品继续构建和工作，不借迁移改变桌面规则。
- 预期用户规模不超过 100 人；这不是已批准的 100 并发 SLA。预算尚未定量，无现成域名；不以本文件授权购买、注册或订阅服务。

## 2. 游客身份、恢复与本地数据

| 数据 | 生命周期与边界 | 必须验证 |
|---|---|---|
| 进行中对局 | 服务端临时会话；同一标签页刷新使用会话凭据与游标恢复；重启、过期或释放可失效，不承诺持久续局 | 刷新不重放命令；旧 revision 同步；响应丢失先确认；失效明确回到开局；服务重启不破坏本地历史 |
| 会话凭据 | 仅是本局访问能力，不是用户账号；获知凭据可访问该局 | 不进入日志、错误报告或共享 Replay；隔离游客、限制容量并回收；日志包含 path/Location/body/异常链时亦须脱敏 |
| Replay | 浏览器持久本地存储，不随临时会话结束而删除；保存/删除由用户操作及明确规则管理 | 关闭重开页面仍能读取；损坏/配额不足不静默丢失；文件可导入导出，网页与桌面双向兼容 |
| 累计战绩 | 当前浏览器、当前站点的数据，不以 sessionId 为用户主键，不承诺可信排行榜 | 多局累计、重复结算幂等、刷新与重开一致；新游客局不清旧战绩 |
| 音量等偏好 | 当前浏览器本地；不依赖临时对局 | 刷新/重开恢复，浏览器阻止自动播放时有可用入口 |

“游客”与“本地历史”不矛盾：无服务器身份，仍可在本机保存数据。换浏览器、设备、无痕窗口或清理站点数据后不自动恢复；同一浏览器配置的共用者可能看见历史，应明确告知。浏览器存储受用户清理、配额及驱逐策略影响，不承诺永久保险库。Replay 文件是手工迁移手段，不承诺累计战绩跨端迁移。

存储受 origin 限制；测试域名到正式域名、协议或端口变化不会自动搬迁数据。WEB-043/045 必须分别覆盖换域、HTTP→HTTPS 与端口变化：旧会话凭据及本地 Replay/战绩不会自动出现在新 origin；不等于旧数据已被删除。正式发布避免无提示改变 origin。未导出的本地数据不能通过服务器回滚恢复。
