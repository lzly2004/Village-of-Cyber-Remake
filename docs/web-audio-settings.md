# WEB-028：音效、音量、静音与设置恢复

基线406eb89。复用026的9个SoundEffect及现有MP3/哈希，不重编码；在027的手势解锁上下文增加一个非循环音效通道。无Java、规则/随机源、协议或游客会话格式变更，不增加依赖。实际验证、失败与审查归档见[review-406eb89.md](review-406eb89.md)。

## 桌面来源与网页时序

`Resources.playSound`按SoundEffect读取WAV、启动Clip、在STOP时关闭Clip和输入流。相关调用点为GameSceneHandler、DialogueDayDeathHandler、DialogueChuxingHandler、EndGameHandler及既有按钮。单测读取这些源码锁定9个用途；未发现资源层/现有桌面UI提供音量、静音与持久化控制，因此本轮网页控件是新的用户设置，不能声称迁移了已有桌面设置格式。

| 用途 | 当前公开展示上的触发 |
|---|---|
| CLICK | 已启用音频后的主页面按钮（包括推进游标、键盘激活）；普通场景切换保留当前交互CLICK，不按旧事件取消。已有音效忙时合并忽略点击，满额场景队列可抢占CLICK；disabled按钮及侧栏同步/音声设置不触发 |
| NIGHTFALL、WOLF_HOWL | 当前局/日首次进入NIGHT_RESULT时，按顺序播放入夜→狼嚎；不按未来phase或隐藏死亡类型推断 |
| PEACEFUL_NIGHT | 当前NIGHT_RESULT/wsw；首次夜结果排在上述两段后，否则直接播放 |
| NIGHT_DEATH | 当前NIGHT_RESULT/yjsw的第二帧实际就绪/显示后，加入当前事件队列 |
| DAY_EXECUTION | 当前EXECUTION/cxs、hzsw、mzsw的第二帧显示后；与桌面共用处刑音效，不从角色身份选择 |
| VILLAGE_VICTORY、WOLF_VICTORY、FOX_VICTORY | 所有事件已确认、原finished门槛成立后，按公开胜负选择一次；SETTLEMENT发言期间不提前播放 |

网页025没有桌面的入夜7秒、狼嚎2.5秒独立等待页，也没有处刑额外两次确认。本轮保持阅读/图片/确认节奏：音频只串行播放实际文件时长，不重建桌面额外等待页，不因音频延长或自动推进游标。首次夜结果的结果音效可能等待入夜/狼嚎播完，**不宣称与桌面画面逐毫秒同步**。用户先确认时，旧场景音效与未播段全部取消，当前交互CLICK按下述例外保留；不把旧狼嚎/死亡音效带进下条事件。启用时不补播已错过的场景音效，刷新后再次启用也不追赶旧音效。

StageArtwork在有效两帧资源完整解码后发一次第二帧通知，App仅转发既有会话ID+绝对游标；减少动态效果时直接后图，同样通知。控制器按事件身份再去重，拒绝旧key、同步不确定与重复手动重看。定时器/通知只控制呈现音效，不调用nextEvent或API、不读私有技能/身份或未来事件列表。坏图仍保持原图像诊断，不伪造对应死亡画面音效。

## 通道、增益与释放

同一手势解锁AudioContext，最多一个循环BGM、一个非循环音效媒体元素；各自MediaElementAudioSource→Gain→destination。音效队列最多3项（含当前项），只消费当前场景；按ended后再请求下一段，不预拉后续场景。连续CLICK在已有音效/队列时合并丢弃，不积累点击队列。普通游标/阶段变化只取消旧场景声音，允许当前交互CLICK完成；新场景队列超过三项容量时，仅抢占CLICK并保留场景队列顺序，仍不新增音效voice或扩大上限。停止、静音、后台、卸载和同步不确定始终取消CLICK，详见[028评审补修](review-73dd9cd.md)。网页有意采用单音效串行，区别于桌面可同时开启多个Clip的行为，以约束混音与内存。

BGM和音效独立0—100整数音量，默认100；各自满档增益0.25（-12.04dB），不是浏览器/设备满幅。按026全库测量峰值计算，最坏一条BGM加一条音效的绝对值上界约0.637181，即-3.91475dBFS；单测锁定小于1。该数学上界不是主观听感/声卡无失真证书，浏览器解码也可能有差异；正式听审仍待统一A08放行。

音量实时更新，不重启BGM；BGM音量0仍推进已启用的曲目。总静音将BGM增益置0，并取消/释放音效队列；静音中或音效音量0不下载/补播音效。取消静音只恢复当前BGM，不重放旧音效。静音不同于停止：BGM可保留播放进度与上下文；停止/后台/离页仍按027暂停、移除src、撤销Blob、abort并suspend/close，音效同样清理。音效结束立即撤销当前URL、清空媒体，保留最多一个空闲节点供下次复用；卸载断开节点。

加载/媒体/拒播/初始化失败、15秒加载播放超时及“源时长+5秒”结束超时均显示有限错误码，不自动循环重试；清理当前音效与队列，BGM和对局仍可操作。部分节点初始化失败不得绕过增益直接播放。版本号拒绝下载/play Promise晚到结果。参考[原生ended事件](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/ended_event)。

## 本地设置

唯一新键`localStorage['vocr.audio.v1']`保存`{version:1,bgmVolume:100,soundVolume:100,muted:false}`。仅上述四个字段；未知版本/额外键/类型错误/非整数/越界/JSON损坏均明确READ_FAILED诊断并用默认值，不显示原始输入。存取被拒或空间不足有独立诊断，当前页仍能调节内存中的设置；成功保存会清除诊断。

每次组件挂载读取，刷新/同origin重开页面可恢复数值；不保存启用状态、播放游标、曲目或音频数据，不触碰vocr.guest.v1和录像/战绩。即使数值恢复为非静音，也不会自动请求目录或创建AudioContext。不同窗口即时同步不在本轮承诺内；按[localStorage的origin范围](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage)隔离，换协议/域名/端口不宣称迁移。

## 验收边界

单测验证资源用途、队列/取消/异常、设置与混音数值。静态音频浏览器测实际媒体/ended、第二帧、减少动态效果/提前确认、终局门槛、实时Float32增益、存储异常及后台释放；测试probe仅包装原生API，无正常播放替身。混音采样在浏览器Web Audio节点，静音后检查零样本，不等于物理设备试听。027旧用例改为分别检查BGM与单音效，不删除BGM取消/释放/隐私断言；真实会话回归同时检查设置操作不写游戏状态。
