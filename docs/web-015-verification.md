## 行为与信息边界

- 直接消费publicInformation，不从玩家职业、预约、原始技能编码或怀疑分数推算结果；不新增API、不缓存公开快照或派生状态。
- 展示全部公开CO报告及CO顺位，包括死亡者、CO前已公开历史、空历史与报告行破绽；占卜/灵能球只按WHITE/BLACK展示，护卫NOT_APPLICABLE无球，不推断实际技能成功或真实身份。
- 怀疑目标、顺序与比较类别完全来自DTO，不重新排名或计算阈值。源码appendVotePanel无非零目标只输出换行，故网页保留空行、不显示观察者名或“没有怀疑”的新含义。此边界以源码、Node与合成DOM验证，未新增Swing逐字实跑。
- 死亡历史仅展示公开白天原因/前缀与夜死编号或平和，不从NIGHT_DEATH猜测精确原因。终局精确死因视觉仍归025。
- 运行中可浏览最新公开快照，含未读事件时也不推进游标；权威已FINISHED但仍有事件未读时隐藏新增面板，读完才显示公开死亡历史，不提前显示结算身份。终局报告/怀疑入口隐藏。
- publicInformation缺失明确显示“不支持”，不能伪装成空报告；未知展示枚举有显式兜底。全部Vue文本插值，不用v-html。页面新文案沿日文方向，不声称旧中文/角色外观标识已全量迁移。
- 浏览/刷新不发游戏写命令，sessionStorage仍仅sessionId/eventCursor；会话失效时面板消失，新局从新权威投影读取。409只同步；已执行失响应先同步、不重放。
