# 仅显示游戏窗口（用户已确认）

用户确认以真实游戏画面为唯一保留区域，去掉网页侧栏、页眉、01标题及外围辅助区。过渡阶段保留入口按钮；进入后按钮也隐藏，Esc恢复外围。覆盖菜单、配役、局内、Info、Record、Replay和结算，不调用浏览器全屏接口。

## Approaches

- 采用用户已选方案：暂时隐藏外围，现有场景保持挂载、音频及会话继续运行；Esc恢复，不留常驻悬浮退出按钮。
- 不采用直接删除外围：过渡期仍需音量设置、诊断及开发辅助操作。
- 不采用浏览器Fullscreen API：它不能替代网页内部区域筛选，会引入额外权限和浏览器退出语义。

## 展示与交互

按1280×720原坐标等比适配可视区、居中，剩余区域深色留边；不拉伸、不引入页面滚动。首次Esc只恢复外围，阻止同次按键关闭Info/Record/Replay或原生确认框；下一次Esc遵循原有场景行为。模式仅存在当前页面内，刷新回普通模式，不写本地存储。

声音组件保持挂载；未启用声音时窗口内允许明确启用按钮，启用后消失。连接/存储错误、再同步和图像等待降级入口在窗口内可达；普通状态不出现外围辅助说明。录像文件交换与必要确认对话框保留，外围管理说明隐藏，不改变保存、覆盖、取消和信息公开语义。

本轮只改前端及文档，不改Java、规则、接口、存档、Replay格式、依赖或资源预算。未实现不记完成；最终截图供用户确认。
