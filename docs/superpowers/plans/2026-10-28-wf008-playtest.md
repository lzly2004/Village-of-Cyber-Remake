# WF-008 完整自助试玩 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.
> 本轮用户明确要求无待决项即直接开发，执行方式沿用本会话Coder实施、用户转交外部独立CR；不另设新的内部评审角色或重复设计批准。

**Goal:** 用户自行启动精确候选版本，正常完整游玩、保存本地历史并反馈，再与独立CR和CI共同形成合流依据。

**Architecture:** 可信工具与候选内容分开；候选导入先复算证据和外部身份，再原子保存。Linux协调器在终端持锁，服务worker受既有guarded-process保护，浏览器在其监护子树之外。full复用发布包；frontend另构建同head preview并对实际解包产物执行真实整局冒烟，不改full24的验收契约。

**Tech Stack:** Python3标准库、Linux flock/Unix socket、已有Java21+/Caddy2.11.7/可见Chromium、既有Node/Playwright仅用于开发与CI。

**Spec:** ../specs/2026-10-28-wf008-playtest-design.md（用户已批准，含CR计划固化意见）

## Global Constraints

- 仅Linux首版；HTTP localhost:18500、后端127.0.0.1:17075；固定端口不回退，不结束他人进程。
- MemAvailable至少2GiB，单JVM安全入口；本轮全量/check/打包另获明确授权后才能执行。
- 完整真实生产功能，无固定种子/假响应/代操作/加速/跳日/隐藏身份作弊。
- 不改生产Java/API/规则/Replay/IDB格式/预算/系统/证书信任；不把HTTP试玩计作043 HTTPS、SAN或正式同源代理验收通过。
- 050外观与日文化、045跨版兼容和run.cmd端口、044日志与hosting-proof归属、046/047/048/049门槛保持。
- 原NTFS脏树不检出/改写；本轮基线main2698ca5，已有设计提交aa37aa5保留。不推送、建PR、上传产物或合流，直到具体发布授权。

## Review Focus

- 陈旧PID/端口竞争/低内存和中断：只清理实际拥有的服务子进程，浏览器和外部哨兵存活。
- 来源伪造或部分包：外部digest/身份/证据/receipt/包内字节全部绑定，full与preview互斥。
- 打开浏览器后profile被占：不能第二次并发使用或静默切版，停止服务不强杀浏览器/删IDB。
- frontend新包：runtime/dist/result同head，实际组合整局冒烟，不声称Java全量已执行。
- 同版历史与会话：历史保存/文件操作可用，后端重启活局明确失效，不虚构持久续局。

## 先固化的接口与8项CR落点

1. **preview schema1**：kind=`vocr-playtest-preview`；source={sha,fingerprints}；runtime={javaMinimum:21,stampSha256}；verification={tier:frontend,status:passed,resultSha256,suites:[{id,status}],javaFull:false}；budgets/budgetLimits复用既有上限；files={相对路径:{bytes,sha256}}；notCovered明确full/人工/公网。包内名称preview-manifest.json+SHA256SUMS，完整生产frontend/backend/config/runtime-stamp/LICENSE。`check_preview(path)->dict`拒绝release-manifest、未知kind、坏文件集/哈希/预算、stamp不符、seed/test入口；既有check_release必须拒绝preview。外部preview-report绑定ZIP/manifest/result和实际冒烟logSHA。
2. **互斥矩阵**：同UID一个试玩协调器锁；18500或17075已占一律`PORT_IN_USE`，提示“043托管或其他服务可能占用；请自行确认并停止，不自动结束”。043标准HTTPS18443/18444及HTTP18080本身与18500不冲突，但共享17075上游仍互斥；043 plain-origin18500/probe等仅在测试配置启用，不误写成标准serve全部监听。18501/18510/18511不由WF008占用；普通应用占18500/17075同样拒绝。菜单显示固定地址。
3. **路径和键**：默认`~/.local/share/vocr-playtest/{candidates,profiles,feedback}`，可显式--home用于隔离实验；候选键`full-<40sha>-<64archivehash>`或`preview-...`，避免同sha不同包互相覆盖。profile以该候选键绑定，`profiles/<key>/chromium`、`downloads`；同包跨启动保留，不自动复制/删除。协调器锁/socket位于`$XDG_RUNTIME_DIR/vocr-playtest`或`/tmp/vocr-playtest-<uid>`，权限0700、所有者和软链检查。
4. **就绪**：对归属确认且启动成功的本次服务只读GET`/api/v1/__playtest_ready__`，严格404/JSON code=HTTP_ERROR；不能用GET /games创建或选择对局。先确认Java实际成功监听（固定启动日志）并防已占端口误连，再检同源代理404与静态index SHA。断言无POST/PUT/DELETE与无用户对局创建。HTTP客户端禁代理环境与重定向。
5. **Caddy**：只用`tools/hosting-toolchain.json`与`web_hosting.checked_caddy`，不增加下载地址；缺失打印显式`host-web.py install-tool`准备命令。运行已缓存候选不联网、不sudo；HTTP配置与043的静态/API边界做结构一致性断言。
6. **状态机/控制**：STOPPED→CHECKING→STARTING→READY→STOPPING→STOPPED；失败→FAILED，原因码至少SOURCE_UNCONFIRMED/CANDIDATE_CHANGED/PORT_IN_USE/PROFILE_IN_USE/LOW_MEMORY/START_FAILED/INTERRUPTED/CLEANUP_FAILED。flock在整个服务周期持有；Unix socket stop/status，不凭磁盘PID发信号。SIGINT/TERM与worker75低内存按原因退出；窗口独立终端，不向游戏页注入控制层，不强制always-on-top/全屏。
7. **feedback schema1**：kind=vocr-playtest-feedback；candidate={key,sourceSha,kind,run,attempt}；environment={os,architecture,browserVersion}；play={configuration,completion:not_started|completed|interrupted}；visual/sound/controls各为{status:not_checked|accepted|problem,comment}；steps=[]；attachments=[{name,bytes,sha256}]；limitations含凭据/隐藏身份及未自动上传提醒。附件仅用户显式指定，复制至feedback/<id>/attachments，默认不录屏录音，不扫描文件。用户编辑结论，不自动标pass。
8. **文档**：HTTP不覆盖HTTPS/证书/SAN/公网；043归档准确区分Coder复算与CR未运行download.py。run.cmd端口留045；旧计划路径纠正为hosting-toolchain.json；044/050等不实施。
